## Phase 9 numbering note

"Experiment 5" was already taken by the historical profit-risk model (`risk_matrix.md`: "Phase 5, Experiment 5 /
Item 1") before this phase started -- it does NOT refer to leave-one-state-out generalization, despite a
same-numbered reference appearing in this phase's task brief. To avoid colliding with the existing E1-E5
numbering already used across `reports/results/*.md`, every NEW Phase 9 analysis is numbered as a sub-item of
the experiment family it extends: E1.4/E1.5/E1.6 (yield), E2.3 (price), E3.4 (optimizer). This is a documented
ASSUMPTION, not a discovery of a pre-existing "Experiment 5 LOSO" analysis -- none was found in
`reports/results/*.md`, `docs/*.md`, or `src/agriopt/backtest/info.py` (searched explicitly); the closest
precedent is E1.3 (`yield_regional.md`), a single-state (Maharashtra-only) preview of exactly this question,
which E1.6 extends to 10 states.
